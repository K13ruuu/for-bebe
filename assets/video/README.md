# Video

Add your video here, named exactly:

message.mp4

Keep it under ~50MB if you can (GitHub has a 100MB per-file hard limit, and large
files make the page slow to load). If your video is bigger, compress it first
(HandBrake is a free, easy tool) or host it elsewhere (YouTube, unlisted) and
swap the `<video>` tag in `index.html` for an embed.
